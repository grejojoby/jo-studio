# Confirmed Intent: Hushline Studio

- Outcome: a minimal, Dockerized web studio that gently polishes exposed vocals.
- User: solo singers and creators on desktop Chrome or Edge.
- Workflow: upload or record multiple complete takes, select one, add an optional backing track, balance, preview, and export.
- Monitoring: hear low-latency effects through headphones while retaining the dry recording.
- Controls: male/female presets and five plain-language macros, plus an optional advanced panel.
- Privacy: no accounts, analytics, cloud storage, or network audio transfer.
- Export: WAV or MP3 for the final mix or processed vocal alone.
- Out of scope: layered vocals, harmony workflows, collaboration, sharing, cloud storage, and mobile recording.
